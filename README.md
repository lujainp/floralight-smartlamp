# floralight-smartlamp
FloraLight is a smart lamp made using embedded systems. In this group project, we used an ESP32 microcontroller and set up HomeAssistant. An I2S microphone, stepper motor, and LD2450 radar sensor were integrated under ESPHome and programmed to work together. Wake words were used to activate voice commands.
